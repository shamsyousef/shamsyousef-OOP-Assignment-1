# OOP Assignment 1

This assignment focuses on applying Object-Oriented Programming principles and design patterns using C#.

## Parts

### Part 1 - Procedural C++ to OOP C#

Refactored a procedural order-processing program into an object-oriented C# implementation.

- Encapsulation
- Classes and Objects
- Responsibilities
- Separation of concerns

### Part 2 - Hotel Reservation System

Designed a hotel reservation domain from requirements.

- Encapsulation
- Domain rules and validation
- Reservation status transitions
- Room maintenance
- Double-booking prevention

### Part 3 - Builder Pattern

Applied the Builder Pattern to construct a complex Invoice object.

- Fluent Builder
- Mandatory property validation
- Composed Builders
- `AddressBuilder`
- `OrderBuilder`
- `InvoiceBuilder`

### Part 4 - LeetCode 1679

Solved **Max Number of K-Sum Pairs** using the Two Pointers technique.

- Sorting
- Two Pointers
- Accepted solution on LeetCode
